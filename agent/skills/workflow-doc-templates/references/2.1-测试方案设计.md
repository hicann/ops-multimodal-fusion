## 5. 测试架构

- 框架：pytest 参数化（`@pytest.mark.parametrize("shape", ...)` × `("dtype", ...)`），自包含 `tests/{op}/test_{op}.py`（无 conftest/CSV）
- 加载守卫：模块级 `if not hasattr(torch.ops.ops_multimodal_fusion, "{op}"): pytest.skip(..., allow_module_level=True)`，并有 `test_{op}_interface_exist` 断言注册
- 设备守卫：`@pytest.mark.skipif(not torch.npu.is_available())`
- Golden：PyTorch CPU 参考（float64 计算后降回目标 dtype 对比），唯一 CPU 参考基准
- 验证：float 用 `torch.allclose(rtol/atol)`，int 用 `torch.equal`
