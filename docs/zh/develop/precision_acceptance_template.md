# 精度验收报告模版

贡献新算子时，须在 PR 描述中附上精度测试报告。报告请参考本模版撰写：复制下方模版内容，将 `${}` 占位符替换为实际内容，未涉及项可标注"不适用"。

精度判定以[生态算子开源精度标准](https://gitcode.com/cann/opbase/blob/master/docs/zh/ops_precision_standard/experimental_standard.md) MERE/MARE 口径为唯一通过依据。

## 精度说明

> 权威口径（[生态算子开源精度标准](https://gitcode.com/cann/opbase/blob/master/docs/zh/ops_precision_standard/experimental_standard.md)，唯一通过依据）：MERE = avg(|actual−golden|/(|golden|+1e-7))，MARE = max(同式)，按「采样点」语义计算；通过条件 **MERE < Threshold 且 MARE < 10×Threshold**，Threshold：fp16=2^-10、bf16=2^-7、fp32=2^-13。

| 输出张量 | dtype | 判定指标 | 阈值（MERE / 10×MARE） | 最差用例 | 实测值（采样口径） | 权威源出处 | 结论 |

| ${name} | float16 | MERE/MARE | 2^-10=9.766e-4 / 9.766e-3 | ${case} | MERE=${x} / MARE=${x} | 精度标准 FLOAT16 | **${达标/不达标}** |
| ${name} | bfloat16 | MERE/MARE | 2^-7=7.812e-3 / 7.812e-2 | ${case} | MERE=${x} / MARE=${x} | 精度标准 BFLOAT16 | **${达标/不达标}** |
